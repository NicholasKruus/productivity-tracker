Fonts for the demo, served from this folder so visitors' browsers make no
requests to third parties.

- `inter-latin.woff2`, `inter-tight-latin.woff2`: Inter and Inter Tight (variable,
  Latin subset). SIL Open Font License 1.1, see `OFL-Inter.txt`.
- `IBMPlexMono-*.ttf`: IBM Plex Mono, unmodified. SIL Open Font License 1.1 with
  Reserved Font Name "Plex", see `OFL-IBM-Plex.txt`.
